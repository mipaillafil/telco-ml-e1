# Telco Customer Churn - Machine Learning

## Descripción

Proyecto de Machine Learning orientado a la identificación
de clientes con riesgo de abandono.

## Dataset

Telco Customer Churn Dataset.

## Estructura

- data/raw: dataset original
- data/processed: datos preparados
- notebooks: desarrollo del proyecto

## Flujo del proyecto

1. Exploración y limpieza
2. Preparación de datos
3. Modelamiento
4. Evaluación
5. Selección mediante criterio de salida

## Modelos

- Regresión Logística
- Random Forest
- Gradient Boosting

## Criterio de salida

- Recall >= 0,75
- F1-score >= 0,60
- ROC-AUC >= 0,80

## Modelo seleccionado

Regresión Logística.
